# SVG screenshot examples

Real FontLab 9.0.9794 Font and Glyph windows with their panels, captured using
an owned CC0 Ocra sample. Open the SVG files directly in a browser.

- `font-window.svg` and `glyph-window.svg`: original-colour compositions with matched SVG icons inlined.
- `*-monochrome.svg`: grayscale versions preserving luminance.
- `*-wireframe.svg`: outlined UI versions with opaque surfaces.

These are unchanged copies of the verified issue 131 gallery screenshots.
Capture metadata remains embedded. Unmatched icons and glyph previews remain
embedded raster images; no external image files are needed.
