# GrabLab sample fonts

Unmodified GetGo VFJs for reproducible FontLab screenshots: GG Plum (variable sans), GG Veni (serif) and GG Ocra (OCR). All are CC0; original family notes and the full dedication accompany them. `sources.json` records source paths and SHA256 hashes. Open a disposable copy for capture examples; keep these fixtures unchanged.
